# VIVOICE visual asset manifest

## Purpose

This register identifies the locally managed public-site photography introduced for the VIVOICE cultural-tourism redesign. It provides an accessible alt-text source and prevents the UI from depending on a remote image host.

## Generation and optimisation

They contain no text, logo or third-party URL. They are stored under `src/Vivoice.Web/wwwroot/assets/`; the public UI must use an explicit visual fallback if an asset cannot load.
